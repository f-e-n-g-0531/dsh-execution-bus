# 独立子进程容量对照

此开发工具比较两个**受信任的本地构建**，不安装、不自动构建、不调用模型。它不随 npm 包发布，也不是 OS 沙箱：构建代码以当前用户权限执行，禁止指向不可信代码。

## 使用

先由构建负责人准备两个完整 dist 目录，勿在采样时重新构建或同时跑测试、安装。以同一构建做小规模工具自测：

```powershell
node dev/compare-capacity.mjs --before dist --after dist --sizes 4 --interrupted 0.5 --iterations 1 --timeout-ms 10000 > artifacts/capacity-selfcheck.json
```

真实对照时，将 `--before`、`--after` 分别改为冻结的完整构建目录。目录需有 runtime/executor.js、store.js、plan.js、service.js，以及根目录 error-codes.js、presentation.js，并可解析原宿主依赖。不得让多个真实宿主同时写同一运行目录。工具只在独立临时目录生成合成历史。

参数：

|参数|默认与边界|
|---|---|
|`--before`、`--after`|必填，完整 dist 目录|
|`--sizes`|默认 `10`；1–10000，最多4个不重复整数|
|`--interrupted`|默认 `0.5`；0–1，最多4个不重复比例；包含 interrupted 与失联 running|
|`--iterations`|默认2；1–10|
|`--timeout-ms`|默认60000；1000–600000，包含子进程启动、准备、验证与清理|

矩阵最多256个子进程，大历史可能需要大量磁盘与时间，先做小样本。每个规模/比例/重复/组独立启动 Node，按规模、比例和重复遍历配对，首组随全局配对序号以 AB/BA 交替；每个操作独立生成历史。首次 list 与同实例 warm-list 属于同历史配对，不是独立重复。子进程不继承 NODE_OPTIONS/NODE_PATH，不使用 shell 拼接命令。

## 报告与退出码

- **0**：所有 worker 回执和合成状态检查通过。这不是业务验收或收益证明。
- **2**：保留完整报告，但至少一个 worker 失败、超时、回执损坏或语义校验未通过；不要把失败时间当零。
- **1**：选项、构建读取或顶层运行错误，只输出固定错误标记，不输出输入路径或原始异常。

每个 attempt 保存组别、顺序、起止时间、总耗时和摘要；失败 samples=null、cleanup=unknown。配对统计只使用两侧成功的配对，同时披露失败及缺失百分比数量；零基线不计算百分比。报告包含均值、中位数和逐对值，不能选择最有利统计口径宣称收益。

构建摘要覆盖当前 11 个已知本地运行时执行文件（旧版六文件必需，retry、agent、agent-report、agent-trace、worker-quota 五模块可缺省；摘要区分缺失与存在，仅 ENOENT 视为缺失），worker 导入前后复核；不绑定第三方依赖、Node 二进制或任意未来新增依赖，升级执行依赖时需更新清单。报告另绑定运行器、基准入口和统计依赖的摘要，父进程在每个 worker 前后复核，持续修改会使该配对失败；这不消除改后恢复的 TOCTOU，也不认证已加载代码。PID 仅用于一致性检查，不是独立认证。

## 边界

新进程隔离模块级缓存，但不清空 OS 文件缓存，也不保证机器独占。`wallTimeMs` 含子进程启动/准备/清理；`operationMs` 沿用原基准的操作计时，不含历史准备。setImmediate 探针不是 CPU 时间或精确阻塞归因。工具未实现逐系统调用分段归因或自动收益门槛。

异常 worker 可能遗留临时历史目录，工具报告清理未知，不自动批量删除。正常 worker 的 completed 仅表示本工具临时目录清理成功，不保证其加载代码没有其他副作用。超时会终止直接 Node worker，不承诺清理受信构建自行启动的任意外部进程。

本工具不替代实际沙箱、桌面、宿主生命周期和真实模型实验。大规模收益结论仍需预登记负载、成功判据、同环境预算，并保留全部异常值和失败配对。

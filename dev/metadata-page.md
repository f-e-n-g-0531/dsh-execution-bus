# 元数据页选择原型（未接入运行时）

该纯函数只处理已经完整校验并物化的元数据数组，不读取或缓存记录，不用于权威读取。`selectMetadataPage(entries,{limit,offset,ownerSessionId})`先过滤owner，用最大堆保留offset+limit个最优条目，再排序取页；k覆盖整个输入时降级完整排序。比较器与当前store一致：updatedAt降序、runId.localeCompare升序，相等再以输入位置保持稳定性。返回原对象引用，不改变输入。limit/offset需非负安全整数，两者相加饱和到MAX_SAFE_INTEGER。

前提是受信已验证普通元数据：字段和owner在调用期间不变，比较器为总预序，不接受NaN/带副作用getter/不一致locale环境。原函数的sort后filter与原型filter后选择只在这一前提下等价。

selector只限制额外保留的条目数，不消除原数组O(n)内存，不限制对象临时分配总量；深offset与全量读取会使k接近n。所有条目仍需扫描，不能跳过磁盘open、双fstat、完整内容校验、owner隔离、页内fresh读取、变更重试或删除前复验。不得用于prune/maintain替代其排序与复验。

五项回归覆盖多seed、多owner、空页、深分页、MAX_SAFE边界、排序相等稳定性、引用不变和输入不变；不是运行时变更下的存储并发安全认证。开发工具不随npm发布。

# 产品结构与维护契约

## 产品边界

萧何是 DSH 内的可选**声明式运行时**插件：模型提交 DAG 计划，运行时按依赖执行宿主工具（read/glob/grep/edit/write/pwsh），负责并行、只读重试、超时、结果落盘、取消与重启后恢复。它不是模型、不是通用工作流引擎、不接管全部工具；权限、沙箱与审批仍由宿主管理。

1.0 移除了 0.x 的执行总线（`execution_bus`、`./core` 导出与总线预设），旧版本保留在 npm/git 历史，不再维护。

## 入口与配置

| 入口 | 谁使用 | 责任 |
|---|---|---|
| 包级 bundle /preset | DSH 配置加载器 | 读取 ptc 声明快照，注册独立预设 `xiao-he-runtime` |
| Agent 内 /mode | 预设末尾插件行 | 追加运行时工具与模式说明 |
| `./test-mode` | 兼容别名 | 与 /mode 同一模块 |

普通任务继续用原工具；运行时只处理“能写成稳定 DAG”的协调工作，简单一次性操作不包装。

## 非目标

- 不做跨进程/分布式执行、不做 exactly-once 副作用回滚、不做跨重启的在途副作用恢复。
- 不替代宿主后台 Job、Teams、Skills、Goals；这些仍是长任务、并行扇出、流程复用的首选。
- 不承诺真实模型/桌面 UI/实际沙箱验收，只提供组件与真实 ToolRuntime 测试证据。

## 维护契约

- 工具名与公开导出变更必须升主版本；工具 schema 变更需同步文档与测试。
- 运行记录格式带 `version:1`；破坏兼容需迁移或拒绝旧记录。
- 发布门禁：全量测试、包白名单、标签 CI 四矩阵、npm 后公开校验、GitHub Release。

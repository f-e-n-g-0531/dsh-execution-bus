## 已知限制

- 并发重复附着现在共享一个宿主 Job 和程序等待者；回归测试断言只新增一个 Job。Job admission 首次失败会取消尚未执行的受理请求。保存期内已完成请求的再次重取可能建立短暂 Job，但不会重新执行 Handler。
- 同一逻辑请求的任一等待工具被取消，会请求取消共享执行；这是本版明确的请求级取消规则，不是独立等待者取消。
- returned 不证明宿主已经持久化或模型已经消费，取消/后置策略仍可能改变最终宿主结果。
- 核心不是独立安全边界；可信插件可以注册 Handler，恶意同进程插件不在威胁模型内。
- 本地源码证据快照不包含在 npm 包中；文档相对证据链接适用于开发仓库提取后阅读，安装包读者应使用所列组件名及构建行号查对应版本。

# 验证范围与使用限制

本文说明当前版本的证据边界，不是生产环境认证。当前能力基线为 **v1.0.0**，验证环境为 Windows、Node.js 24、DSH 0.2.1-rc.2、Cordis 4.0.4。

## 已验证

| 层次 | 检查内容 | 能说明什么 |
|---|---|---|
| 计划 schema | DAG、依赖、环、工具白名单、retry 限制、大小/超时/并发上限、未知字段 | 非法计划在进入执行前被拒绝 |
| 执行器 | 独立步骤并行、依赖顺序、只读重试、超时、失败阻止依赖、取消、结果截断 | 组件级 DAG 语义可重复检查 |
| 持久化 | 原子写、损坏记录忽略、列表/prune、启动 `running→interrupted`、恢复语义 | 文件记录与重启标记逻辑成立 |
| 真实宿主组件 | Cordis ToolRuntime + 真实 `ctx.tools.execute` 链路（read/pwsh 桩） | 工具经真实管线执行；Agent/工具实现为夹具 |
| 预设与模式 | 派生预设注册、默认预设不变、普通 Agent 不可见运行时、宿主策略拒绝仍有效 | 隔离与权限边界成立 |
| 发布门禁 | 全量测试、包白名单、四矩阵 CI、npm 后逐字节校验 | 发布制品一致性 |

本地全量 **27** 项测试通过（以 `npm run check` 实际输出为准）。

## 未验证或明确不支持

| 项目 | 结论 |
|---|---|
| 真实模型/桌面 UI/实际沙箱 | 未验收；组件测试与桩不等于桌面/模型验收 |
| 真实进程崩溃 + 重启恢复 | 只验证了记录标记与恢复逻辑，未做 kill 进程后的端到端恢复验收 |
| exactly-once 副作用 | 不支持；崩溃时在途副作用可能已发生，只能标记 unknown/failed |
| 跨进程/分布式执行 | 不支持；运行时随宿主进程退出 |
| 大结果/长计划 | 单步结果 >64KiB 截断；计划 ≤64KiB、32 步 |
| 宿主版本漂移 | 依赖 DSH 0.2.1-rc.2 的 ToolRuntime/preset 契约；升级需复核 |

## 使用约束

1. 运行记录在本地内存/磁盘；进程退出后仅保留已落盘状态，不恢复在途副作用。
2. 计划质量由模型决定；稳定流程适合，探索型任务用原工具。
3. 取消是合作式的：副作用步骤可能停在 unknown；不要假设取消等于回滚。

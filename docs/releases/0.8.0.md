# 萧何 / Xiao He 0.8.0

## 宿主工具覆盖面扩展：搜索与命令

本版沿用 0.7.0 的通用 `hostToolHandler` 工厂与 `makeHostInvoke` 抽象，新增三个宿主工具 Handler。

- 新增 `host.glob`（`pattern` / `path?`）与 `host.grep`（`pattern` / `path?` / `include?`）：只读、幂等，终态结果可复用；沿用宿主工具的工作目录、忽略规则与结果上限。`include` 只接受单个正向 glob，不支持取反（`!`）或顶层逗号列表。
- 新增 `host.pwsh`（`description` / `command` / `timeoutMs?` / `workdir?` / `run_in_background?` / `sandbox_permissions?` / `justification?`）：有副作用、非幂等，同一 requestId 的终态结果不可复用，重复提交返回 `MUTATING_REUSE_DENIED`；运行中的重复附着仍只等待同一执行。`sandbox_permissions` 只接受 `workspace-write` / `danger-full-access`，且必须与 `justification` 成对出现，与宿主 pwsh/sandbox 契约一致。
- 命令仍由宿主 `pwsh` 工具经 shell 执行器、沙箱与审批链执行；插件不自行启动进程。后台模式只返回宿主 Job ID，不等于命令完成。
- 新增错误码 `INVALID_GLOB_INPUT`、`INVALID_GREP_INPUT`、`INVALID_PWSH_INPUT`；既有错误码、协议字段与 `host.read` / `host.edit` / `host.write` 行为不变。

## 升级说明

需要 DSH 0.2.1-rc.2。本版不强制把原工具改成总线调用，普通任务仍使用原工具；`host.glob` / `host.grep` / `host.pwsh` 只在你显式提交总线请求时执行。不自动安装、重写日常配置或重启 DSH。历史预设、配置行、工具名、协议字段与既有错误码均不变。

## 验证与限制

本地全量 93 项测试通过（含 host.glob / host.grep / host.pwsh 的转发、参数校验与幂等分流回归；搜索与命令 Handler 的转发测试使用宿主工具桩，不是真实搜索/命令实现），包白名单校验通过。真实 glob/grep/pwsh 工具实现、真实模型、桌面 UI 与实际沙箱仍未完整验收；状态为进程内存，不支持跨重启恢复。有副作用 Handler 的外部副作用对账仍不在本版范围。

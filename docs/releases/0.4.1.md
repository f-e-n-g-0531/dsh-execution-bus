# 萧何 / Xiao He 0.4.1

## 优化

结合固定版本的 p-queue、EventEmitter3 和 Denque 实现/测试对照，收敛诊断热路径开销，保持 0.4.0 执行语义。

- 诊断最近 128 条轨迹改为固定槽位环，写入不再 shift 搬移旧项；快照仍按时间顺序复制。
- 保存结果时缓存字节数，过期时扣除、关闭归零；diagnostics 查询不再遍历所有结果和重复序列化。结果快照失败或 unknown 不占缓存。
- 增加三项对比回归及可追溯 GitHub 对比说明。1000 条事件的 shift 从 872 次降为 0；两个结果查询诊断 50 次的额外序列化从 100 次降为 0。不是速度提升比例。

## 兼容与验证

不改变消息协议、工具或预设标识、会话轮转/通知重入/关闭契约；不新增运行依赖。全量测试、标签 Windows/Ubuntu × Node 22/24、包白名单与生产隔离安装按既有门禁执行。

DSH 0.2.0-rc.2，非商业源码公开许可。真实模型、桌面 UI 和实际沙箱未验收，不支持跨重启恢复，不安装或重启日常 DSH。

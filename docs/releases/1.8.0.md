# 萧何 / Xiao He 1.8.0

## 变化

- 能力查询与运行存储初始化解耦：未初始化时 `capacityBusy:null` 明确表示未知，查询不检查或获取根锁；有锁时仍可读静态说明，实际运行保持 fail-closed，并提示人工核对。
- 本地会话统计覆盖全部 13 个运行时接口，增加项目/来源筛选、预设切换分段、根会话与子会话分母、执行/观察/控制请求分类，以及缺失结果和样本质量投影。保留旧统计字段，输出不含业务路径或正文。
- 普通工具 DAG 选择指引前置：参数和依赖已明确且确需保存、只读重试或中断核对时优先使用；简单操作、动态探索和独立模型分析保留原生路径，不以提高调用率为目标。
- 宿主兼容 smoke 实际注册插件和探针，以正向对照、具体拒绝原因、双 owner 隔离、root/parent 传播及零 Worker 创建断言替代“任意报错即通过”。矩阵记录候选和实际宿主身份，区分未执行/安装失败/执行失败/通过。
- 崩溃回归夹具等待真实 exit/close，并在测试锁核对与恢复前要求旧 PID 返回 ESRCH；生产存活判断、锁和未知副作用不重放规则未放宽。

## 兼容与验证边界

- 本版重点适配 DSH 0.2.2-rc.3。只有逐版本实测证据覆盖的范围可声明支持，不保证整个 V0.2 系列或未来版本兼容。
- `capacityBusy` 的读取方须处理新增的 null 未观察状态；不能将它当作 false。来源不明日志不按根会话推断，运行请求不等同任务成功或收益。
- 标准入口仍未接入可信父策略适配器，含 agent 的计划继续以 `RUNTIME_AGENT_POLICY_UNSUPPORTED` 拒绝；原生委派和普通工具 DAG 不代表 Worker 门禁已打通。
- 本地使用锁文件安装的 rc.3 SDK：完整回归 676/676 通过、0 失败/跳过，崩溃专项另连续 8 轮通过，151 个包文件核验和同候选隔离生产安装通过。组件和 stub host 不代表真实环境验收，先前 rc.1 工作树测试不移作 rc.3 证据。
- 历史崩溃恢复间歇失败没有确定唯一根因；退出前置条件收紧不是生产崩溃问题零缺陷证明。真实模型、桌面、OS 沙箱、整宿主生命周期及收益对照仍未独立验收。
- 正式发布不会自动安装、升级或重启日常 DSH。

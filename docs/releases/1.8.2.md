# 萧何 / Xiao He 1.8.2

## 变化

- 纯只读 DAG 在步骤终败后停止派发新调用，包括退避中的重试；已发出的调用仍按原规则收束。修复恢复刚受理就取消时可能误报的存储故障。
- 知悉同一个未知副作用不再改变通知投递身份，仍保留核验提醒和匹配的已有回执。Worker 决策处置后不再误报待答复，未复核的完整结果仍进入待复核列表。
- 严格查询不再因诊断计数饱和而漏报读取故障。新 Worker 计划拒绝非法 Unicode 提示词，旧检查点仍可读取。
- 宿主矩阵拒绝空清单，容量基准指纹覆盖实际测量依赖；恢复指南明确硬崩溃遗留锁的离线处置和断电边界。

## 使用边界

- 重点适配 DSH 0.2.2-rc.3。标准插件仍拒绝未接入可信父策略适配器的 Worker 计划；只读 Worker 和未知副作用不重放规则不变。
- 发布以四矩阵标签 CI、隔离安装和公开制品核对为准，不代表真实桌面、模型或 OS 沙箱验收，也不会自动安装、升级或重启日常 DSH。

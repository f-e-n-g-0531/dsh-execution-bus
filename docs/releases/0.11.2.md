# 萧何 / Xiao He 0.11.2

## 修正 PTC 预算测试在 CI 的时序抖动

- 0.11.1 的标签 CI 在 **windows-latest + Node 22** 上失败：真实 PTC 预算用例只给 `run_code` 2 秒预算，不足以覆盖 CI 冷启动 PTC 子进程的时间，导致“总线请求尚未受理就已超时”（测试夹具时序问题，不是产品缺陷）；因此 0.11.1 未发布。
- 调整测试夹具：PTC 预算 2s→8s、被测命令 5s→12s、等待上限同步放宽，保证“已受理后预算到期”路径在慢速 CI 上稳定复现。本地连续 3 次通过。
- 0.11.1 的提示与文档修正（同程序内不要对未完成请求轮询 status；启动步骤尽早结束程序、后续步骤用同 requestId 取回）一并包含在本版。
- 无产品运行时代码、协议或 Handler 行为变化；全量 110 项测试通过。

## 升级说明

需要 DSH 0.2.1-rc.2。行为与 0.11.0 一致，仅修正提示/文档与测试时序。不自动安装或重启 DSH。

# 萧何 / Xiao He 1.7.3

## 修复

- 将模型工具入口的运行存储初始化从预设挂载延迟到首次调用 `runtime_*`。崩溃遗留目录锁或存储初始化失败不再使整个萧何预设加载失败，继承的普通工具仍可挂载。
- 插件卸载会关闭尚未初始化的入口；残留工具引用不能在卸载后重新打开存储。已初始化实例仍沿用原取消、收束与释放流程。

## 使用影响与安全边界

- 本版不自动移除、抢占或改名 `.runtime-owner.lock`，不切换记录目录，也不自动重放任务。锁冲突仍在运行时工具调用时以 `RUNTIME_ROOT_LOCKED` 拒绝。
- 预设可加载不等于运行存储可用；遗留锁仍须按[运维说明](<../OPERATIONS.md#中断记录与敏感数据>)停止相关宿主、备份记录并核验外部工作后离线处置。
- 直接使用公开 `RuntimeService` 的宿主集成仍在构造时初始化；本版仅改变模型工具插件入口。

## 验证与限制

- 本地 TypeScript 编译及全量回归 650/650 通过，0 失败、0 跳过。覆盖遗留锁下的真实注册表挂载、全部 13 个运行时工具拒绝访问且不改锁、首次调用初始化、卸载前后生命周期及隔离安装检查夹具。
- 首轮全测因隔离安装夹具仍假设挂载立即创建目录而失败；已改为调用工具后验证隔离目录，未放宽操作者目录保护。
- 标签 CI、生产候选隔离安装及公开产物以发布流水线结果为准，不在本说明中预先宣称通过。实际桌面、真实模型及旧目录离线恢复尚未验收；不宣称修复宿主内存不足崩溃。正式发布不自动安装或重启日常 DSH。

# 执行总线 0.1.0

## 本版变化

第一阶段纯插件原型：版本化协议、有界队列、请求复用与冲突检查、原工具异步等待、宿主 Job 进度、受控测试 Handler 和宿主只读 read 接入。测试与发布流程参考 dsh-vcs，标签触发四矩阵 CI，正式发布独立手动门禁。

## 安装

提供 npm 包 @feng0531/dsh-execution-bus@0.1.0 和同包 GitHub Release 安装制品；发布过程不安装到日常 DSH。兼容目标 DSH 0.2.0-rc.2。请先阅读 README 和宿主兼容说明，选择隔离配置。

## 限制

非持久化、不支持跨重启原调用恢复，不提供任意命令执行。真实模型、GUI、桌面沙箱、PTC 全链路尚未验证。采用非商业源码公开许可证，非 OSI 开源许可；商业项目内部使用及有偿交付需要另行书面授权。

## 验证

真实宿主组件与 AgentLoop 内存会话采用脚本模型隔离测试；不能当作真实模型端到端通过。具体本地测试数与检查结果见 docs/validation.md。GitHub Actions 四矩阵及正式发布尚未执行。

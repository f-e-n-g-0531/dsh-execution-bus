# 萧何 / Xiao He 0.2.7

## BUG 修复

- core 构造器补齐完整配置校验：不传参数仍使用默认值；显式配置须包含 concurrency、queueLimit、recordLimit、resultBytes、retentionMs 五项正安全整数。缺项、额外字段、非对象及访问器立即 INVALID_OPTIONS，避免受理后因缺少并发配置而不执行。不扩展部分配置契约。
- 每个附着使用独立监听注册，复用同一回调时，解除一个附着不再移除其他附着的进度和终态通知。每个活跃监听附着独立占用名额；detach 可重复执行。

## 验证与限制

新增三项回归：不完整和异常配置拒绝、默认及完整配置正常调度、共享回调独立解除与名额上限。两个缺陷用例修复前失败，修复后全量与正式发布门禁验证。

不改变工具/预设标识。真实模型、桌面 GUI 和 PTC 完整链路未验收，不支持跨重启恢复。DSH 0.2.0-rc.2，非商业源码公开许可，发布不自动安装或重启 DSH。

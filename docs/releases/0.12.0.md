# 萧何 / Xiao He 0.12.0

## 调度隔离、资源互斥与唯一任务（开源机制整合）

本版把一组调度/可靠性机制收敛进总线。参考来源、实际阅读范围与许可见 [整合说明](<../INTEGRATION.md>)；本轮未复制第三方源码、未新增运行依赖。

- **Handler 调度声明**：新增可选 `queue`（类别）、`maxConcurrency`（舱壁）、`resources(input)`（资源键）、`dedupe:"payload"`（唯一任务）；注册时校验（`INVALID_HANDLER_OPTIONS`/`INVALID_RESOURCES`）。
- **调度**：同会话内按类别优先级（fs < diagnostic < command < default）+ 等待老化（每 30 秒削平一级，最多两级）选择；跨会话仍按会话轮转；`maxConcurrency` 限制同一 Handler 并发。排队期限、取消、关闭与结果语义不变。
- **资源互斥**：`host.edit`/`host.write` 以 `file:<file_path>` 为资源键，在同一总线实例内串行执行；失败/取消/关闭释放资源；排队期限继续生效。**不是 OS 文件锁或跨进程保证。**
- **唯一任务**：`host.read`/`host.glob`/`host.grep` 声明 payload 去重；同会话同 handler+input 已有 `succeeded` 终态时，新 requestId 直接复用快照并返回 `reused:true`，不重复执行 Handler；失败/取消/unknown 不缓存。
- **诊断**：`execution_bus_state` 任务增加 `longRunning`（运行超过 30 秒）；`waitReason` 增加 `resource`。
- **开发验证**：新增 8 项调度/唯一/资源回归、2 项 fast-check 属性回归与 2 项插件级 Handler 回归；全量 **122** 项测试通过。fast-check 仅 devDependency（MIT），不进入 tgz。

## 升级说明

需要 DSH 0.2.1-rc.2。wire 协议与工具调用形状不变；新增能力只在 core/Handler 层，宿主预设、工具名与既有错误码不变。默认调度对内置 Handler 生效（类别优先级与文件互斥），如需完全旧行为应自行评估 effect。不自动安装、重写日常配置或重启 DSH。

## 验证与限制

本地全量 122 项测试通过；属性测试固定种子，不是穷尽证明。调度与资源锁只在单个总线实例内；跨会话/跨进程/OS 级互斥、外部副作用对账、持久化与自动重试均未实现。真实模型、桌面 UI 与实际沙箱仍未完整验收。

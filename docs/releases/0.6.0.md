# 萧何 / Xiao He 0.6.0

## DSH 0.2.1-rc.2 兼容与 Handler 幂等约束

本版把兼容目标对齐到 DSH 0.2.1-rc.2，并在 core 层为扩展 Handler 增加可声明的幂等约束。

- 兼容目标升级为 DSH 0.2.1-rc.2：五个宿主 peer 依赖由 0.2.0-rc.2 升至 0.2.1-rc.2，锁文件重建。0.2.0-rc.2 宿主应继续使用 0.5.x。
- 新增 Handler.idempotent 声明。显式 idempotent:false 时，终态结果复用被拒绝并返回 MUTATING_REUSE_DENIED；运行中的重复 attach 仍只等待同一个执行，不会二次执行。省略该字段默认幂等，保持既有 handler 与调用方行为。
- 内置 test 与 host.read 显式声明 idempotent:true。
- 适配 0.2.1-rc.2 新增的 workingDirectory 服务：真实宿主组件测试为 read/run_code 路径注入最小 stub，不改变插件运行逻辑。

## 升级说明

需要 DSH 0.2.1-rc.2。升级前先停止新请求，等待已有任务完成或请求合作取消。本版不自动安装、重写日常配置或重启 DSH。

历史预设 execution-bus-test、配置行 preset-execution-bus-test、工具名、协议字段和既有错误码均不变；错误词汇仅新增 MUTATING_REUSE_DENIED。

## 验证与限制

本地全量 76 项测试通过（含新增幂等回归、真实宿主组件与 Node PTC 组件测试），包白名单校验通过。真实模型、桌面 UI 与实际沙箱仍未完整验收；状态仍为进程内存，不支持跨重启恢复。

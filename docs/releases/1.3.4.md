# 萧何 / Xiao He v1.3.4

本版适配 DSH **0.2.2-rc.1**，配套 Cordis ~4.1.0、include ~1.1.0。需要新宿主的用户使用本版；旧版 1.3.3 面向 0.2.1-rc.5，不据此追认交叉兼容。

## 变化

- DSH peer 与测试组件统一精确锁定 0.2.2-rc.1，同步更新包检查、锁文件和隔离安装检查。
- 新宿主 tools.execute 改为批接口；运行时嵌套步骤通过公开 ToolExecutionPipeline 的 prepare、dispatch、complete 调用，保留 parent、rootCallId、agent、signal，并透传本步 toolSet 准入集合。宿主策略、guard 与结果处理仍生效，不直接调用工具体绕过权限。
- 真实 native/PTC 集成使用新版独立执行器与公开测试辅助接口；新增条件工具准入、调用身份透传及 guard 拒绝回归。外置构建测试补齐宿主依赖解析，不改变失败分类断言。

计划格式、工具名、逐步 checkpoint、取消、只读重试及 unknown 副作用不自动重放的规则保持不变；不接入 top-k 或改变批次调度。安装和启用方式见[README](<../../README.md>)。

## 验证与限制

适配阶段在 Windows、Node v26.13.0 完成 252 项测试（0失败、0跳过）、88 文件包检查，以及同一离线候选的 production-only 安装，实际 DSH peer 均为 0.2.2-rc.1。该候选不是本版最终字节；本说明发布前冻结，本版最终本地验证、Windows/Ubuntu × Node22/24 标签CI和两端公开字节核验以实际流水线为准。

真实模型、桌面 UI、实际 OS 沙箱和整宿主重启仍未验收；PTC full-access 夹具、shell bridge 和 stub 安装不代替这些验收。不保证 exactly-once 或回滚，取消不证明不合作工具或 Job 已停止。发布不自动安装、升级或重启日常 DSH。

2026-11-05 完整锁定依赖树 audit 仍报告36个受影响包节点（33 high、3 moderate），根包 undici 8.11.2、zod 4.4.3；不是36个独立漏洞，也非生产可达性评估。宿主升级不表示告警修复，详见[宿主兼容性](<../host-compatibility.md>)。

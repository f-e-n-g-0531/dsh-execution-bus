# 萧何 / Xiao He 1.3.1

面向 DSH 0.2.1-rc.5 的维护补丁，不改变工具接口或记录格式。

## 变化

- 保存 checkpoint 成功 rename 后，不再对已被消耗的唯一临时路径执行冗余清理；写入失败、rename 失败的清理和排他创建规则保持不变。
- 发布脚本增加可注入的离线测试边界，覆盖上传结果不确定、已有版本、公开元数据状态和字节核验；仅明确404才允许一次上传，不增加写入重试或绕过发布门槛。
- 仓库新增独立子进程容量对照开发工具，记录配对顺序、源码/构建摘要、失败样本与缺失统计；该工具不随 npm 包发布。
- 修正研发文档中的已发布基线表述，真实环境验收仍与版本发布分开。

## 行为与性能边界

每步checkpoint、owner隔离、删除前fresh读取、未知副作用停止恢复、仅只读重试和最新100条终态保留规则不变。没有跨进程共享root支持、exactly-once或断电耐久保证。

独立进程合成对照仅在部分1k恢复启动场景观察到改善，10k场景未形成一致收益；本版不承诺启动、查询或清理提速。组件耗时不等于模型收益，不是OS冷缓存或机器独占实验。

## 验证与发布

该代码快照已完成本地235项回归（0失败、0跳过）；本版本候选仍须按[发布流程](<../RELEASING.md>)完成重新构建、包白名单、同候选隔离安装、Windows/Ubuntu×Node22/24标签CI及公开字节核验。本文在上传前冻结，不预先宣称远端发布已完成。

目标宿主仍为DSH 0.2.1-rc.5。真实模型、桌面、实际OS沙箱与完整宿主重启仍未验收。上游undici/zod风险未由本版修复，见[宿主兼容性](<../host-compatibility.md>)。发布不自动升级、安装或重启日常DSH。

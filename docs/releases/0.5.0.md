# 萧何 / Xiao He 0.5.0

## 有意义的同类项目整合

阅读固定提交的同类 DSH 队列/限流插件与 MCP 执行项目相关源码和测试后，重新实现适合本插件的能力，不直接合并第三方源码或新增运行依赖。

- 宿主插件新增每会话排队上限 16（全局仍 32），拒绝错误 SESSION_BACKPRESSURE；重复请求复用不重复占名额。不是全局入队公平保证。
- 默认排队期限 120 秒，仅尚未运行任务到期 failed / QUEUE_WAIT_TIMEOUT，保证不调用 Handler。计时器及出队均校验单调期限，运行任务仍使用原合作取消，不超时强杀或自动重跑。
- 新增 execution_bus_state({}) 只读工具，身份来自宿主 Agent，拒绝匿名或自报身份；只返回本会话元数据/计数/策略，最多 50 项、活跃优先，其余终态按最近受理排序。不含输入或结果，不创建 Job。没有 UI 面板。
- core 原五项 options 不变，第二参数可选配置 AdmissionPolicy；不传策略保持旧行为。inspect(trustedOwner) 为可信嵌入方接口，不是独立鉴权系统。

## 验证与限制

新增准入、期限、竞态、关闭计时器、隐私隔离、活跃优先及策略校验回归；真实宿主和 Node PTC 验证状态工具与身份规则。120 秒语义用缩短 core 期限测试，默认值由宿主组件检查，不声称真实模型/桌面沙箱已验收。

不引入数据库、租约、崩溃重排、自动副作用重试或独立进程池。普通 PTC 工具能力、宿主权限/沙箱、总线原始调用等待不变。DSH 0.2.0-rc.2，非商业源码公开许可；不安装或重启日常 DSH。

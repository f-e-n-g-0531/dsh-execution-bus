# 萧何 / Xiao He 1.8.3

## 变化

- 修复关闭重入可能提前释放或遗留运行目录锁的问题；仍在清理的运行不再因历史缓存淘汰而被误标为未知。
- 普通已知悉事项保留详情，但不再计入紧急待办或置顶；未知副作用仍提示核验。修复合法 Worker 报告的决策请求可能从摘要消失的问题。
- 容量基准不再将错误结果计入成功耗时；会话统计标记快照成员缺失。未改变查询实现，不声明性能提升。
- 加固安装隔离、标准 Worker 恢复拒绝和生成物一致性检查；补齐工具索引。

## 使用边界

- 重点适配 DSH 0.2.2-rc.3，包含 1.8.2 的修复。标准插件仍拒绝未接入可信父策略适配器的 Worker 计划；只读 Worker 和未知副作用不重放规则不变。
- 发布验证不等于真实桌面、模型或 OS 沙箱验收，也不会自动安装、升级或重启日常 DSH。

# 萧何 / Xiao He 1.1.1

本版包含 1.1.0 标签中尚未正式发布的运行时改进，并修复新版 Node 24 在损坏 zstd 帧前后恢复有效日志的兼容性问题。1.1.0 因标签 CI 失败未上传 npm、未创建正式 Release，原标签保留。

## 运行可靠性与资源治理

- 同一记录目录在单进程内共享活跃运行与 8 个运行配额；新作用域不再误中断仍在执行的任务，运行与恢复统一准入。
- 每次工具调用前、步骤完成及重试时保存检查点；保存失败停止后续调度，已保存成功步骤在恢复时不重放。
- 取消及时停止调度，隔离晚到结果；同步运行绑定外层取消，异步受理后脱离外层信号。未知副作用使整个恢复计划失败，不自动重发；只读超时不重试，避免重叠调用。
- `pwsh` 仅正常零退出视为成功；非零退出阻止下游，显式后台参数在预检拒绝，自动转后台保留 Job ID 供原生 Job 工具收集，不视为执行完成。
- `runtime_status` 新增本会话 `limit` / `offset` 分页和脱敏存储诊断；过滤所有者后分页。持续保留最新 100 条终态，保护活跃及中断记录。
- 完整校验 version 1 记录，读取前限制 4MiB，隔离损坏记录并清理原子写失败的临时文件；合法 64KiB 计划不会因归一化默认字段而保存失败。

## 指标与升级

- 本地会话指标支持 `runtime_*` 与 `xiao-he-runtime`，按运行/步骤去重；兼容旧总线统计，不把请求次数推断为执行成功。默认不输出业务输入或结果正文，不发送网络遥测。
- npm 包名、预设 ID、六种叶子工具及五个运行时工具保持不变。旧 version 1 记录仅在校验通过后读取，损坏记录隔离而非自动修复；新版本命令和恢复判定更加保守。
- 仍依赖 DSH 0.2.1-rc.2、Cordis ~4.0.4、Node ≥22。使用会话指标的 zstd 解压需支持该能力的 Node 构建（22.15+ 或 23.8+）。

## 验证与限制

运行时改进已在本地 Windows / Node 22.21.1 与 24.21.0 的 93 项测试中验证；本版日志解压修复须重新执行完整门禁，结果以对应 CI 为准。测试覆盖真实子进程 kill 后恢复、双会话隔离、真实 ToolRuntime 嵌套权限拒绝、存储故障注入、非合作取消及真实 pwsh 工具和命令进程。正式标签四矩阵 CI 与公开制品核验结果以对应 Actions 记录为准，不在上传前预写通过结论。

命令测试使用的 shell bridge 不等于实际沙箱。真实模型、桌面 UI、实际沙箱及收益对照试用仍未验收；不保证 exactly-once、工具必定响应取消或副作用回滚，不提供跨进程锁或分布式队列。正式发布不会自动安装、升级或重启日常 DSH。

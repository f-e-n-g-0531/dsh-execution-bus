# 萧何 / Xiao He 0.11.0

## 收益导向触发、简化调用与复用可见

根据 0.10.0 的采用率 pilot（4 个全新队友会话）结果，本版收紧触发条件并降低调用摩擦。

- **触发收紧**：只在能获得协调收益时使用总线——同一逻辑操作可能重复提交或需要重试去重（沿用 requestId）；任务需要在 `run_code` 预算结束后继续或跨步骤取回；多个步骤/等待者需要同一执行结果。**仅“操作耗时长”不再作为理由**：一次性长命令使用原工具或宿主后台 Job（pilot 中一次性 40 秒命令被包装后没有协调收益）。
- **简化调用**：请求可传 `{requestId, handler, input, messageId?}`，控制可传 `{requestId, type:"status"|"result"|"cancel", messageId?}`；`messageId` 省略时自动生成。完整 v1 消息仍被接受（向后兼容）。工具 schema 改为简化调用的 Handler 判别联合，PTC SDK 不再要求构造完整消息。
- **复用可见**：附着到已有执行（终态复用或运行中重发）时，返回快照追加 `reused:true`；首次执行不带该字段。该标记只表示复用了逻辑执行，不代表外部副作用对账。
- **采用率观察**：新增只读命令 `npm run metrics:sessions`，扫描本地会话日志并汇总总线请求/Handler/复用/错误，供后续两臂 A/B 比较。
- 新增/重写 9 项回归（简化请求与控制、完整 v1 兼容、复用标记、非法形状拒绝、schema/SDK 渲染、收益导向提示），全量 **110** 项测试通过。

## 升级说明

需要 DSH 0.2.1-rc.2。wire 协议结构、预设、工具名、错误码与 Handler 行为不变；工具入口新增简化形状并保留完整 v1 消息。不自动安装、重写日常配置或重启 DSH。

## 验证与限制

本地全量 110 项测试通过。0.10.0 pilot 样本小且任务由本仓库构造：符合条件任务 2/3 使用总线，不是 A/B 结论；0.11.0 收紧后的采用率与轮次/耗时收益仍需两臂复测。真实模型、桌面 UI 与实际沙箱仍未完整验收。

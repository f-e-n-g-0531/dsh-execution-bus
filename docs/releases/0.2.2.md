# 执行总线 0.2.2

> 历史版本说明：名称、能力和验证结论以该版本发布时为准，不代表当前版本状态。当前行为与限制请阅读 [README](<../../README.md>) 和[验证范围](<../validation.md>)。已发布标签及安装包不会因本文后续澄清而改变。

## BUG 修复

- 终态提交先准备返回快照再更新状态；深层结果或快照构造失败会明确结算为 unknown / RESULT_NOT_RETAINED，避免原工具调用和关闭流程永久等待。
- 普通消息额度耗尽后为首次取消保留一个额外槽；最多 129 条记账，重复取消不增加内存，不绕过已记录消息 ID 的冲突检查。
- 输入和结果采用严格无损 JSON 校验，拒绝 NaN、Infinity、负零、undefined、函数、稀疏数组、循环和特殊对象，避免静默改写成成功结果。JSON 深度最多 64，访问节点最多 65536；不自动重跑保存失败任务。

## 验证

新增 5 项回归，覆盖 1800 层结果、注入快照克隆故障、消息额度耗尽取消、无损返回值和不执行 getter 的输入拒绝。本地全量 31/31 测试通过；仍须标签 Windows/Ubuntu × Node 22/24 四矩阵 CI、候选一致性、隔离安装及公开包核验通过才能发布。

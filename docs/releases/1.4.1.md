# 萧何 / Xiao He v1.4.1

本补丁修正 1.4.0 的异步准入边界，并补齐开发基准的构建身份摘要。目标宿主仍为 DSH **0.2.2-rc.1**、Cordis ~4.1.0、include ~1.1.0、Node ≥22；不覆盖已发布的 1.4.0，也不把新宿主支持追认给旧公开版本。

## 变化

- 携带批次 `exec.toolSet` 的普通工具计划，在 `async:true` 或 service 后台提交时于创建 run 前拒绝，错误码为 `RUNTIME_ASYNC_ADMISSION_UNSUPPORTED`。宿主批次结束会销毁该准入集合，没有公开续租接口；不得删除准入集合或重新解析以绕过限制。含 Agent 的异步提交仍优先返回 `RUNTIME_AGENT_ASYNC_UNSUPPORTED`。同步调用，以及无批次准入集合的受控宿主调用，保持原异步行为。
- 容量基准、独立进程对照和调用归因改为绑定当前 11 个已知本地运行时执行文件。旧构建的六个文件仍为必需；retry、agent、agent-report、agent-trace、worker-quota 仅在缺失时按旧构建兼容，其他读取失败不视为缺失。

安装和启用方式见[README](<../../README.md>)；协议细节见[协议](<../protocol.md>)。

## 验证与限制

本说明发布前冻结。本版 Windows/Ubuntu × Node 22/24 标签 CI、npm 公开字节和 GitHub Release 核验以实际流水线及公开制品为准，不预先声称已通过。

检查点在原子替换前 fsync 临时文件内容，不保证目录项级持久性或断电事务；首次写入也无上一检查点可回退。真实模型、桌面 UI、实际 OS 沙箱和整宿主重启仍未验收；不保证 exactly-once 或回滚，取消不证明不合作工具或 Job 已停止。发布不自动安装、升级或重启日常 DSH。

锁定依赖树 audit 仍报告受影响包节点（33 high、3 moderate，非生产可达性评估），详见[宿主兼容性](<../host-compatibility.md>)。

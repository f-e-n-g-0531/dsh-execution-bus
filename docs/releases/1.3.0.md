# 萧何 / Xiao He 1.3.0

本版面向 DSH 0.2.1-rc.5，改进历史记录查询及研发验收准备。

## 变化

- 历史列表使用有界、可失效的派生元数据，返回记录前仍完整读取并核对会话归属。恢复、清理和 checkpoint 不以缓存为权威。
- 减少启动恢复和终态清理的重复扫描；不改变每个新 scope 发现遗留记录的行为。冷扫描仍是同步操作，不宣称启动完全不阻塞。
- 新增候选字节绑定的收益实验清单，记录模型、输入快照、权限、并发和实验方案的可追溯摘要。模板或校验通过不代表实验已执行。
- 容量基准区分新实例首读与同实例暖查询；首读不是 OS 冷缓存，组件耗时不是模型收益。
- 修正当前验证文档中的旧版本基线，保留历史事实及未验收边界。

## 不变的行为

默认仍为批次 DAG 调度；工具名、记录 version 1、同步接口、checkpoint、只读重试、未知副作用停止恢复、owner 隔离和最新100条终态保留规则不变。没有自动重试副作用，也不增加跨进程共享目录支持或断电耐久承诺。

## 验证与限制

本地完整构建与175项回归通过，无失败、无跳过；84文件包白名单及同候选纯生产依赖安装通过。跨平台结果以标签 CI 为准。真实模型、桌面、实际 OS 沙箱及完整宿主桌面重启仍须隔离验收，不能用组件测试或合成负载代替。发布不会自动安装或重启当前 DSH。

缓存只保留最多16,384条瘦元数据，另有4MiB逻辑数据计费上限；这不是精确V8堆内存测量。超过预算或路径、owner过长时可能频繁失效，收益不保证。冷暖列表仍同步枚举和核对文件，清理、恢复安全复验可能增加I/O，不承诺所有容量场景加速。

上游 undici/zod 告警未由本版修复，风险与兼容性边界见[宿主兼容性](<../host-compatibility.md>)。本版不是依赖安全修复版。

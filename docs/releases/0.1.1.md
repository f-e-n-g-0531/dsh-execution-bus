# 执行总线 0.1.1

## 本版变化

本版为 BUG 修复，无新增业务执行能力。

- 修复 core 多个结果消费者共享可修改终态快照，可能污染后续重复请求结果的问题；终态快照改为深度冻结。
- 修复 Handler 已完成但返回值无法 JSON 序列化时被误记执行失败的问题；记录为 unknown / RESULT_NOT_RETAINED，不自动重跑。
- 修复没有新请求时过期结果仍能查询/重取的问题；控制消息入口补上 TTL 清理。
- 增加不安装插件的可复用流程测试命令 npm run test:flow，以及三项修复前失败、修复后通过的回归测试。

## 安装与许可

npm 包 @feng0531/dsh-execution-bus@0.1.1，兼容目标 DSH 0.2.0-rc.2；建议先用隔离配置。非商业源码公开许可，具体以 LICENSE 为准。发布不自动安装、升级或重启日常 DSH。

## 验证与限制

本地全量 24/24 测试通过；真实宿主组件、AgentLoop 内存会话均为隔离测试，模型侧使用脚本适配器，不等于当前会话直接调用 execution_bus。真实模型、GUI、PTC 和桌面沙箱未验收；不持久化、不支持跨重启恢复。正式发布仍需同标签四矩阵 CI、包白名单、候选一致性、隔离安装与公开 npm 包核验全部通过。

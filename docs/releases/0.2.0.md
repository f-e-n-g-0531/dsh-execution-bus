# 执行总线 0.2.0

> 历史版本说明：名称、能力和验证结论以该版本发布时为准，不代表当前版本状态。当前行为与限制请阅读 [README](<../../README.md>) 和[验证范围](<../validation.md>)。已发布标签及安装包不会因本文后续澄清而改变。

## 新增功能

新增可选 Agent 预设“执行总线测试 / Execution Bus Test”，通过标准 dsh.bundle.patch 声明，出现在宿主 Agent 预设自定义列表。无需修改宿主前端或 DSH 源码。不会改变默认模式或已有会话。

预设使用原生工具呈现，仅在选中预设的 Agent 作用域注册 execution_bus。提供文件工具套件和 Job 控制，通过作用域 guard 拒绝除总线、read、job_list/job_output/job_kill 外的执行；文件套件声明的写入/编辑工具可能仍可见，但调用会拒绝。预设不是独立进程安全沙箱，宿主权限仍生效。

## 使用

固定安装 @feng0531/dsh-execution-bus@0.2.0，并经宿主正常方式加载包内 cordis.patch.yml bundle。设置 → Agent 预设 → 自定义 → 执行总线测试，创建新会话试验。不要加载包根入口为全局工具，也不要将测试模式设为默认。发布不会自动安装或重启日常 DSH。

## 验证和限制

真实 AgentPresetRegistry/Loader 隔离测试验证预设成功激活、默认不变、普通 Agent 不可见总线、PTC 普通 Agent 不受测试 native 模式影响、写入被拒绝。桌面实际卡片渲染与当前会话切换未验收。相同测试预设共享队列容量，请求结果仍按会话隔离；没有跨重启恢复。不承诺其他会话在进程资源层面完全不受影响。

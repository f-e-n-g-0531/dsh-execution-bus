## 变化

- 研发路线区分已实现能力、开发原型与待真实验收事项，以 v1.3.2 作为本轮工作的历史公开基线。性能工作先确认实际负载与预算，再决定是否实现，当前不接入 top-k。
- 新增[研发准备与决策记录](<../RESEARCH-READINESS.md>)，提供专用隔离环境、候选身份、历史负载、分页习惯、响应预算和继续／停止条件的填写模板。未知值保持待确认，填写完整不构成操作授权或验收通过。
- 包检查要求该文档存在，仍按精确路径白名单分发；新增准备状态回归和文档缺失拒绝断言。
- 验证说明明确：工作树或包内容变化后必须重新绑定候选 SHA，不能借用已发布包的通过结论。

## 使用与限制

从准备记录填写实际需求与专用环境标识，再按既有流程建立候选绑定的验收账本和模型实验配置。不填写凭据、私人路径或业务内容，不用示例预算冒充真实需求；安装包不包含源码仓库 dev 工具。

真实模型、桌面 UI、实际 OS 沙箱、整宿主生命周期及收益实验仍待执行。本版不安装、升级或重启日常 DSH。依赖告警未修复：2026-11-04 完整锁定依赖树审计仍报告 33 个受影响包节点（30 high、3 moderate），不是 33 个独立漏洞，也不是生产可达性评估。

# 萧何 / Xiao He 1.8.5

## 本版变化

- `dist` 构建产物校验改为批量读取 Git 对象，仍与提交中的产物逐字节比对，拒绝缺失、多余或内容不同的文件。
- 判定是否待复核时，若没有所有者的复核声明，则跳过不需要的复核快照计算；公开快照、通知键及复核判定不变。
- 增加四条主链的[维护导航](<../PRODUCT.md#维护导航>)及链接回归检查。
- 补充[普通工具 DAG 中断恢复示例](<../FLOW-TEST.md#普通工具-dag-中断恢复示例>)和原生 PTC 对照步骤。

## 使用边界

宿主依赖、存档格式、检查点顺序、只读恢复和未知副作用不重放规则不变。标准入口仍拒绝无可信父策略适配器的 Worker 计划。隔离宿主的真实对照尚未执行；组件测试不代表生产收益。

# 萧何 / Xiao He 0.10.0

## 让总线可被采用：触发条件与类型化声明

本版不改变执行机制，专门改善“模式被选中但总线从未被调用”的采用问题。

- 模式说明新增明确触发条件：仅在预计单次宿主操作超过约 30 秒、同一逻辑操作可能重复提交（沿用 requestId）、任务需要在 `run_code` 时间预算结束后继续、或多个步骤需要等待同一执行时才使用总线；其余任务继续直接用原工具，并给出一条调用示例与 messageId/requestId 语义。
- `execution_bus` 的模型可见参数从泛型 `payload: Record<string, JsonValue>` 改为按 Handler 的判别联合（`host.read` / `host.glob` / `host.grep` / `host.edit` / `host.write` / `host.pwsh` / `test` + 空控制 payload）。PTC SDK 与原生工具声明现在直接显示每个 Handler 的必填/可选字段；wire 结构、校验、错误码、状态机与 Handler 行为不变。
- 工具描述同步写明触发条件与编号语义；诊断 Handler 仍标注仅用于明确诊断。
- 代价：模型可见声明变大。模式说明 916 字符（+319），`execution_bus` 的 SDK 参数声明约 4.1KB（原泛型声明约 1.3KB）；是否换来更高的真实采用率与更好的结果，需要 pilot 与同任务 A/B 对照验证。
- 新增 4 项回归（判别联合结构、合法/未知 Handler 校验、SDK 渲染、提示触发条件），并扩展真实 Node PTC 用例断言装配后的 SDK 含类型化声明。

## 升级说明

需要 DSH 0.2.1-rc.2。本版只有模型可见提示与工具 schema 变化；请求结构、字段、预设、工具名、错误码与 Handler 行为均不变。不自动安装、重写日常配置或重启 DSH。

## 验证与限制

本地全量 105 项测试通过。真实模型采用率、轮次/耗时收益未验证，需 pilot 与 A/B 对照；真实模型、桌面 UI 与实际沙箱仍未完整验收。若 pilot 显示声明开销不值得，可回退为较短的泛型声明。

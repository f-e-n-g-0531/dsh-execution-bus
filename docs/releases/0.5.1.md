# 萧何 / Xiao He 0.5.1

## 正式产品结构整理

本版修正 test-mode 误导命名并梳理内部职责，保留执行能力和兼容规则，不通过更名宣称生产环境已全部验收。

- 正式实现移至 mode 模块；新增 /mode 导出，新派生预设默认使用它。/test-mode 是同模块兼容别名，旧源/构建文件只保留重导出，不维护两套插件。
- 产品身份、core/准入默认策略、读取/诊断限制、工具参数和模式提示集中到 product，减少重复定义漂移。
- 真实业务 host.read 与诊断 test 明确区分：兼容保留 test，但提示模型只在用户明确诊断时使用，不将其描述成真实业务处理能力。
- 增加正式/旧入口模块身份、默认策略与提示契约测试；真实 Loader 和生产隔离安装检查正式入口。

## 升级说明

先安装 0.5.1 或以上，再将 Agent 预设末尾叠加行改为 @feng0531/dsh-execution-bus/mode；旧版本没有该导出。旧配置不会自动重写且继续可用，不要同时放新旧两行。包级注册入口仍是 /preset，不能与 Agent 内入口混填。

历史预设 execution-bus-test、配置行 preset-execution-bus-test、工具名和协议不改，避免已有会话关联失效。普通 PTC、权限/沙箱、每会话16项和排队120秒等策略不变，不新增运行依赖。

不自动安装、重写日常配置或重启 DSH。真实模型、桌面 UI 与实际沙箱仍未完整验收；不支持跨重启恢复。

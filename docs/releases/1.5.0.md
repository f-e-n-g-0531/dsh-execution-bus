# 萧何 / Xiao He v1.5.0

本版新增"执行之后"的判读与复核能力：能力查询、恢复摘要、待复核结果汇总、待处理事项与等待原因视图，以及 owner 复核处置记录。目标宿主仍为 DSH **0.2.2-rc.1**、Cordis ~4.1.0、include ~1.1.0、Node ≥22；不改变既有 DAG 执行语义、安全边界与 Worker 门禁。

## 变化

- 新增 `runtime_capabilities({})`：返回普通 DAG／Worker／异步能力与限制说明。`worker:"conditional"` 仅表示可信适配器与父 `toolSet` 同时存在，标准插件入口仍为 `unavailable` 并继续在执行前拒绝含 `agent` 的计划；查询不构成授权、资源预留或真实模型可用性探测。
- 单 run 摘要（run/status/result/cancel/resume）新增 `recovery` 派生字段（resultCertainty／cleanup／externalWork／nextAction／message）；`runtime_result`（含分页）另含 `acceptance` 自报汇总：`status` 恒为 `not_reviewed`，只汇总 Worker 状态、结果哈希与报告计数，不回显报告自由文本。
- 摘要与状态列表新增 `attention`（外部核验、失败、待决、结果缺失与待复核事项排序，附稳定 notification 键）与 `waiting`（dependency／scheduler／retry_backoff 及真实退避观察）派生视图；展示卡优先呈现待处理事项，常规逐步进度收敛到 JSON。两者均为派生投影，不持久化、不改变执行语义。
- 新增 `runtime_review`：为完整成功且已收束的运行记录 owner 处置（accepted／needs_work），绑定结果快照 SHA-256 与 revision 乐观并发，最多 32 条历史，写入经每 run `.review-lock` 排他互斥。accepted 仅为 owner 会话声明，不是人工或独立验收；摘要提供 `ownerReview` 投影，result／review 返回 `ownerReviewHistory`，理由不进入展示元数据。
- 容量基准与包白名单绑定新增的 attention／insights／waiting／review 运行时文件；离线安装 smoke 覆盖七个运行时工具注册。

安装和启用方式见[README](<../../README.md>)；协议细节见[协议](<../protocol.md>)。

## 验证与限制

本说明发布前冻结。本版 Windows/Ubuntu × Node 22/24 标签 CI、npm 公开字节和 GitHub Release 核验以实际流水线及公开制品为准，不预先声称已通过。

ownerReview、attention、waiting、recovery、acceptance 均为派生投影或 owner 声明，不构成独立验收、执行授权或提醒已送达证明；attention 不持久化通知收据，waiting 仅本进程活观察、重启不补猜历史等待时间。runtime_review 不开放给 Worker 与普通 DAG 步骤；崩溃遗留 `.review-lock` 需按协议离线处置，不在线清锁。真实模型、桌面 UI、实际 OS 沙箱和整宿主重启仍未验收；不保证 exactly-once 或回滚，取消不证明不合作工具或 Job 已停止。发布不自动安装、升级或重启日常 DSH。

锁定依赖树 audit 仍报告受影响包节点（33 high、3 moderate，非生产可达性评估），详见[宿主兼容性](<../host-compatibility.md>)。

# 萧何 / Xiao He 0.3.0

## 能力补全

本版将萧何从只读验证模式改为“宿主 PTC 工具组合 + 可选执行总线”。加载时读取目标宿主已声明的 ptc 组合快照，保留原配置、平台表达式和禁用项，再追加总线和使用说明。移除萧何的 native 强制呈现与只读白名单。原预设、默认选择及技术 ID 不变。

普通终端、编辑、搜索、技能、委派等任务仍调用原工具，经过宿主原有授权、沙箱与工作目录规则，不强制走总线。总线仍仅支持 test / host.read；不能把命令启动或 Job ID 当成完成。源 PTC 中禁用的专用插件管理工具不会自动启用。

## 升级注意

**旧只读模式升级后工具能力扩大。** 请先审阅目标 PTC 配置再加载，新建专门会话验证；不自动安装或重启日常 DSH。需要宿主先提供 ptc 声明，缺失时最多等待约 5 秒后报错，不静默回退。源预设编辑不会自动热同步；按宿主正常方式重载派生行后，新会话使用新快照，已有会话遵循宿主版本保留规则。

公开 readDocument 不提供原声明 baseUrl，因此本版拒绝含相对模块/include 文件的组合，避免错误重定位；不声称兼容全部自定义 PTC。源预设的组件缺失、策略禁止或禁用项会继续影响能力。

## 验证

声明保真测试覆盖分组、禁用管理工具、!!js 平台表达式；真实 Cordis 生命周期和 AgentPresetRegistry 验证派生注册、write/edit 保留、宿主拒绝策略继续生效、原 PTC 未被修改、原 Agent 不可见总线。真实 Node PTC 子进程验证 run_code 同时调用原 read 和执行总线。

PTC 测试采用显式 danger-full-access 策略与测试 Agent，不能视为桌面沙箱、真实模型或所有日常工具的全链路验收。不提供真实模型性能提升比例。无持久化或跨重启恢复能力。

非商业源码公开许可，宿主兼容目标仍为 DSH 0.2.0-rc.2。

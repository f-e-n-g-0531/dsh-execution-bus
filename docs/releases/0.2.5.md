# 萧何 / Xiao He 0.2.5

## BUG 修复

- Handler 注销函数绑定唯一注册令牌并支持幂等清理。旧注销函数重复执行不会误删后来同名注册，即使复用相同 Handler 对象。已受理请求继续使用它捕获的旧 Handler，新请求使用当前注册。
- 事件和 payload 在通知观察者前深度冻结，前一个观察者无法污染后续观察者收到的 requestId、sequence、type 或进度。同步/异步异常继续隔离。

## 验证

新增三项回归，覆盖相同对象重新注册、已受理任务与替换 Handler 并存、前序观察者修改事件被隔离；三项在修复前均失败。全量测试、标签四矩阵 CI、包内容、生产隔离安装及两端公开包一致性按既有门禁验证。

## 边界

兼容目标仍为 DSH 0.2.0-rc.2，不更改品牌或技术标识。真实模型、桌面 GUI 与 PTC 完整链路未验收；不支持跨重启恢复。非商业源码公开许可，不自动安装或重启 DSH。

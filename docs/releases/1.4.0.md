# 萧何 / Xiao He v1.4.0

本版在 1.3.4 的 DSH 0.2.2-rc.1 适配之上新增 PTC 多 Agent 编排与运行时增强。目标宿主仍为 DSH **0.2.2-rc.1**、Cordis ~4.1.0、include ~1.1.0、Node ≥22；旧公开 1.3.3 面向 0.2.1-rc.5，不据此追认交叉兼容。

> **安全兼容边界：**标准 DSH 0.2.2-rc.1 没有"仅补查父级缺失策略且去重公共层"的公开接口。本插件入口未接入可信 `DelegationPolicyAdapter`，含 `agent` 的 run/resume 在执行前以 `RUNTIME_AGENT_POLICY_UNSUPPORTED` 拒绝；普通工具 DAG 不受影响。下述 Worker 执行能力仅适用于显式注入该适配器的受控宿主集成。

## 变化

- 新增 `tool:agent` 步骤：经公开 `agents.create` + `agentPresets.composeFrom` 创建独立上下文只读 Worker（仅 `read/glob/grep`、read-only 沙箱、approval never、NativeToolExecutor、与父 admission 取交集），不依赖提示词做权限；含 Agent 的计划拒绝 `async:true` 与 service 后台，Agent 不重试、不自动重放，恢复遇未知 Agent 失败整个 run。
- Worker 生命周期配额：同 root 单进程最多 8 个 Worker，创建、执行、清理全程占槽，满载以 `RUNTIME_AGENT_CAPACITY_EXCEEDED` 失败不排队。
- 结构化报告与逐项自报：`output_format:"report"` 严格校验 16KiB 纯 JSON（`outcome/summary/evidence/limitations` 与可选 `requestedDecision`）；可选 `acceptance_criteria` 要求逐项自报观察结果。报告合格仅表示执行成功，不构成独立验收，`succeeded` 不代表验收通过。
- 追溯：步骤与摘要新增可选 `workerTrace`（promptVersion/promptHash/taskPromptHash/selectedModel/requestModels），不进入结果 value 或依赖 JSON，不占用单步 64KiB 配额。
- 计划关联：可选 `task_id`/`previous_run_id` 关联同 owner、同 task 的已结束并清理完成的前驱，仅历史关联，不复用结果、不扩大授权。
- 只读工具重试改为结构化错误分类：权限、参数、资源不存在等确定性错误不重试，已知瞬态可重试，未知错误保留旧行为；退避 100/200/400ms 且可取消；超时仍不重试。
- 结果分页：`runtime_result({runId,stepId,offset,limit,hash})` 按 Unicode 码点分页读取已保存结果，SHA-256 防跨版本拼接，截断内容不恢复；摘要新增可选 `executionSettled` 观察本进程清理收束，不证明普通工具退出。
- 入口注入扩展为 tools/systemPrompt/agents/agentPresets/workingDirectory 五项；新增 7 个 0.2.2-rc.1 DSH peer 依赖，包检查、安装检查与发布白名单同步覆盖新产物。

安装和启用方式见[README](<../../README.md>)；协议细节见[协议](<../protocol.md#agent-步骤受控宿主集成>)。

## 验证与限制

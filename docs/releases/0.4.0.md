# 萧何 / Xiao He 0.4.0

## 本版变化

统一交付引擎调研中优先级最高的生命周期优化，不改变请求级取消、内存保存或宿主权限规则。

- 内部执行句柄集中持有完成结果、请求取消及宿主 Job 投影，core 仍是执行状态唯一事实源。共享执行只由首个附着投影进度，重复调用不重复创建 Job。
- 关闭分阶段、可重入并幂等，多次 close 返回同一完成 Promise，等待已启动执行和活跃工具交付后释放关联。
- 固定事件通知批次：回调中新增监听不接收当前事件，解除监听跳过尚未调用部分；嵌套取消/终态按序派发。事件仍不可变，观察者异常继续隔离。
- core 增加 diagnostics()：最近 128 条数值阶段轨迹及容量快照，内部执行所有者另计 Job 事件。无业务参数、结果、请求/会话 ID 或错误文本，无新增模型工具。
- 压力验证后将已受理调度改为按会话轮转，保持会话内 FIFO；不抢占、不保证入队公平或完成时间。

## 验证和范围

新增通知重入/关闭、诊断脱敏及多会话调度回归。确定性用例 B0 从 A 的 12 个积压任务之后提前至 A1 后执行，不代表真实模型性能提升；具体顺序与边界见优化说明。

沿用 PTC 声明派生，原工具不强制经过总线；Handler 仍只含 test/host.read。资源锁、DAG、线程池、对象池、跨重启恢复不在本版。真实模型、桌面 UI 和实际沙箱仍未验收。兼容 DSH 0.2.0-rc.2，非商业源码公开许可；不安装或重启日常 DSH。

# 萧何 / Xiao He v1.7.2

本版为测试与文档补丁，不改变运行时逻辑、工具接口、权限或存储语义。

## 变化

- 预设集成测试改用独立临时运行记录目录，并在断言失败的路径上也清理资源、恢复环境变量；消除默认环境下外部运行目录状态引起的 `RUNTIME_ROOT_LOCKED` 偶发失败。不删除锁文件、不放宽运行时锁检查，该失败也不是产品缺陷修复。
- 测试侧新增存储失败脱敏取证：检查点保存失败时输出有界的 code/syscall 白名单摘要，原异常对象与 cause 保持不变；诊断输出自身失败不会遮蔽保存失败。新增确定性故障注入回归覆盖异常身份、cause 保留与摘要脱敏。
- 原型对照记录补充 2026-11-10 全仓逐行重读结论：216 个跟踪文件全覆盖台账、两个仅原型自身的静态问题（旧注册清理器可删除后续注册、内容哈希去重压掉独立通知事件）及依赖工具链声明警示；未确认新的必要运行时功能，既有采用与不采用处置不变。

## 兼容与使用

目标宿主仍为 DSH 0.2.2-rc.1。标准插件的普通工具 DAG 可用；含 agent 计划仍因缺少可信父策略适配器而拒绝。未知副作用不自动重放，不保证 exactly-once。许可与依赖告警不变，发布不会自动安装、升级或重启日常 DSH。

## 验证与限制

本地默认并行全量回归 647/647 通过、包白名单与文档契约测试通过；历史间歇性 `RUNTIME_STORAGE_FAILED` 根因仍未确定，本版只改善取证，不宣称已修复。

本说明在发布前冻结；最终候选回归、包白名单、隔离安装、四矩阵标签 CI 和公开制品一致性以实际输出及 Actions 为准，不预先声称发布成功。真实桌面 GUI、真实模型、实际 OS 沙箱与整宿主重启仍未验收。

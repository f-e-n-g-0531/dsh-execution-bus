# 萧何 / Xiao He v1.2.2

## DSH 0.2.1-rc.5 兼容

- 将宿主 peer、测试依赖及锁文件统一到 0.2.1-rc.5，Cordis/include 声明对齐宿主 4.0.5/1.0.10，解决旧版精确 rc.2 peer 与 rc.5 宿主冲突。只承诺本次目标 rc.5，不放宽到未验证候选版。
- 打包门禁校验完整宿主 peer 集合；新增锁文件防混用 rc.2 回归。生产候选安装验证实际安装的 DSH peer 版本，而不只检查入口可导入。
- 相关公开类型接口未发现差异，运行时源码、工具协议、逐步 checkpoint、unknown 和取消语义均保持不变，不为兼容性改写安全边界。

## 安装验证安全修复

- 修复生产安装烟测虽在临时工作目录、却继承真实运行记录根的问题。现在子进程显式使用临时 DSH_HOME 和 XIAOHE_RUNTIME_DIR，避免初始化插件时恢复或裁剪操作者记录。新增两个外部记录根的101条终态与失联运行哨兵回归，验证逐字节不变。此问题是既有脚本隔离缺陷，不是 rc.5 接口变更。

## 验证与限制

使用 rc.5 包执行构建、全量自动化、真实 ToolRuntime/Node PTC 子进程及文件/命令测试；结果以实际测试及标签四矩阵 CI 为准。未自动安装本插件或重启当前 DSH；真实模型、桌面 UI、实际 OS 沙箱及完整桌面宿主重启仍未验收。

当前宿主依赖链的 npm audit 告警未消除；具体版本、受影响节点计数和部署限制见[宿主兼容性](<../host-compatibility.md>)。本版为功能兼容补丁，不是依赖安全修复版。

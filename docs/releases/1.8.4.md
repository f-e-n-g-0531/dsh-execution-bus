# 萧何 / Xiao He 1.8.4

## 变化

- 适配 DSH 0.2.3-alpha.2（Cordis 4.2.0-alpha.1、include 1.2.0-alpha.1）。include 1.2 移除了 `entryListSchema`，预设派生改用 `parseEntryYaml`；仍保留 1.0/1.1 的 js-yaml 回退，无法识别的方言直接失败，不静默解析。
- 修复宿主升级后 `preset-xiao-he-runtime` 组件启用失败：`The requested module ... does not provide an export named 'entryListSchema'`。
- peer 范围增补 0.2.3-alpha.2、Cordis 4.2.0-alpha.1 与 include 1.2.0-alpha.1；开发、测试与隔离安装目标同步锁定 0.2.3-alpha.2。
- 测试夹具跟进新宿主：真实 SystemPrompt 服务执行初始化钩子；PTC 夹具显式使用 `per-call`；`run_code` 不再回传完成值后，PTC 断言通过受控输出标记取回 JSON。
- 宿主兼容矩阵新增 0.2.3-alpha.2 目标。

## 使用边界

- 重点适配 DSH 0.2.3-alpha.2，包含 1.8.3 的修复。标准插件仍拒绝未接入可信父策略适配器的 Worker 计划；只读 Worker 和未知副作用不重放规则不变。
- 发布验证不等于真实桌面、模型或 OS 沙箱验收，也不会自动安装、升级或重启日常 DSH。

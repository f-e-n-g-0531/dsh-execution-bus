# 萧何 / Xiao He 1.7.5

## 修复

- 修正隔离安装检查：宽范围 peer 不再让 npm 自由混装不同 alpha/RC，而是先安装一组一致的 DSH 0.2.2-rc.3 SDK，再安装候选包，并按 semver 校验每个 peer 落在声明范围内。
- 1.7.4 标签 CI 在四个平台均因该安装检查失败而停止，npm 未发布；本版修正后重新发布。

## 宿主兼容

- DSH V0.2 宿主 API 分代适配：0.2.0/0.2.1 使用公开单调用工具执行管线，0.2.2 alpha/RC 使用公开 `ToolExecutionPipeline`。不通过工具 body、私有 guard 或手动 hook 绕过宿主策略。
- 兼容旧版与 rc.2/rc.3 Agent 创建契约：旧版保留 `parentAgent`，新版使用调用上下文生命周期；Worker 仍保留只读、无审批、Native executor 与可信父策略适配器门禁。
- peer 依赖扩展为已审计的 V0.2 兼容范围；缺少对应公开 API 或 Native executor 的版本不强行安装。

## 验证与限制

- TypeScript 构建、全量回归、包白名单、候选打包、隔离安装检查及 `git diff --check` 通过。
- 隔离矩阵记录于 `artifacts/host-compatibility-results.json`：早期版本因 Native executor 包不存在而严格安装失败；部分 0.2.2 矩阵 smoke 仍待修正，不能据此宣称全部 V0.2 版本已验收。
- 本版不自动安装、升级或重启日常 DSH；真实桌面、模型和 OS 沙箱仍需独立验收。

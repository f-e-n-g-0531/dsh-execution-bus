# 萧何 / Xiao He 1.0.0

## 从执行总线切换为声明式运行时

本版把项目从 0.x 的“执行总线模式”整体改造为**声明式运行时**：模型提交 DAG 计划，运行时负责并行、只读重试、超时、落盘、取消与重启后恢复。

## 破坏性变更

- 移除 `execution_bus` / `execution_bus_state` 工具、完整 v1 消息信封与 `./core` 导出。
- 预设 ID 从 `execution-bus-test` 改为 `xiao-he-runtime`；bundle patch 行随之调整。
- 工具面改为 `runtime_run` / `runtime_status` / `runtime_result` / `runtime_cancel` / `runtime_resume`。
- 0.12.1 是最后一个总线版本，保留在 npm/git 历史与标签中，不再维护。

## 新能力

- 计划：DAG（`depends_on`）、并发 1–4、只读 `retry`、单步超时、32 步/64KiB 上限、严格 schema 校验。
- 执行：独立步骤并行、依赖顺序、结果落盘、单步结果 >64KiB 截断。
- 生命周期：`async`、status/result/cancel/resume；启动时把残留 `running` 标记为 `interrupted`。
- 隔离：运行记录按会话隔离；工具经宿主管线并沿用父调用权限。

## 明确不做

- 不保证 exactly-once：崩溃时在途副作用可能已发生，只能标记 `unknown/failed`。
- 不做跨进程/分布式执行、不做跨重启的在途副作用恢复。
- 不替代后台 Job / Teams / Skills / Goals。

## 升级说明

需要 DSH 0.2.1-rc.2。旧总线用户请保留 0.12.1 或迁移到 `runtime_run` 计划；本版不自动安装/重启 DSH，也不迁移旧运行记录（旧记录不读取）。

## 验证与限制

本地全量 **27** 项测试通过（见 `npm run check` 输出）；真实模型、桌面 UI 与实际沙箱未完整验收；崩溃恢复仅验证逻辑与标记，未做真实进程 kill 端到端验收。

# 萧何 / Xiao He v1.2.1

## 修复

- 会话指标脚本在未指定 `--sessions`、未设置 `DSH_HOME` 时，使用操作系统用户目录下的 `.dsh/sessions`；修复 Linux 上错误回退到当前工作目录而漏计会话的问题。显式目录和 `DSH_HOME` 优先级不变。
- 日志树遍历不再跟随目录/文件符号链接及 Windows junction，仅接受普通日志文件，避免链接循环、别名重复计数和扫描所选目录树以外的日志。显式选中的根目录仍可为链接；本工具不是抵御并发文件系统替换的安全沙箱。
- 新增默认 HOME 与目录链接回归；运行时工具、计划协议、version 1 运行记录和执行语义不变。

## 验证边界

本版修复离线指标采集问题，不代表真实模型、桌面 UI、实际沙箱或完整宿主重启已验收。全量本地测试、标签四矩阵 CI、同一候选生产依赖安装和公开制品核验分别以实际执行结果为准。已披露的大量历史记录同步扫描性能风险仍未修复。

# 萧何 / Xiao He 0.2.4

> 历史版本说明：名称、能力和验证结论以该版本发布时为准，不代表当前版本状态。当前行为与限制请阅读 [README](<../../README.md>) 和[验证范围](<../validation.md>)。已发布标签及安装包不会因本文后续澄清而改变。

## BUG 修复

- 隔离事件观察者返回 Promise 的异步拒绝，避免异步日志/通知回调形成未处理 rejection 并导致进程退出。通知不阻塞执行或终态结算，不将观察者异常原文写入日志。
- 严格 JSON 校验补齐数组原型检查，拒绝数组子类和自定义原型，避免继承的 toJSON 改写结果后仍报告成功。原生数组保持可用；core 跨运行域数组需先转换为当前运行域原生 JSON 数据。

## 验证

新增三项回归：严格 unhandled-rejections 子进程中异步观察者拒绝不退出、数组子类/自定义原型拒绝且序列化钩子不执行、原生数组结果完整保存。修复前两个缺陷测试失败，修复后全量测试及标签四矩阵发布门禁验证。

## 使用边界

本版不增加执行能力，保留萧何名称及所有技术标识。观察者通知为最佳努力，不等待异步通知完成；观察者自己的资源仍应自行管理。真实模型、GUI、PTC 完整链路未验收；不支持跨重启恢复。非商业源码公开许可，发布不自动安装或重启 DSH。

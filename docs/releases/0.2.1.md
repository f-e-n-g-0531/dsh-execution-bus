# 执行总线 0.2.1

## 本版变化

规范正式产品命名：Agent 预设显示名统一为“执行总线 / Execution Bus”，不再带“测试 / Test”。用途、只读限制及验证边界保留在描述中，不用显示名称暗示完整生产验收。

兼容标识不变：预设 ID execution-bus-test、配置行 ID preset-execution-bus-test、工具名 execution_bus 和 /test-mode 导出继续保留，避免已有配置或会话失联。这些是历史内部标识，不是显示名称。

## 使用与限制

在宿主正常加载 bundle 后，从设置的 Agent 预设自定义区域选择“执行总线 / Execution Bus”。不改默认预设，不向普通 Agent 注册全局总线。当前用户选择只发布暂不安装，所以实际桌面卡片仍未验收。预设不是进程隔离沙箱，仍不支持跨重启恢复。

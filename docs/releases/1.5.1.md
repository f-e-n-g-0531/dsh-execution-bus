# 萧何 / Xiao He v1.5.1

本版仅修正宿主插件列表中的显示名，不改变运行时、工具协议、安装入口、安全边界或数据格式。

## 变化

- 插件列表显示名改为“萧何 / Xiao He”，不再显示 npm 包名 `@feng0531/dsh-execution-bus`；与 Agent 预设卡片及其他面向使用者的产品名称一致。
- 按目标宿主 DSH 0.2.2-rc.1 的 locale meta 契约新增并导出 `locale/en.json` 与 `locale/zh.json`，标题和简介随宿主语言显示。宿主活动语言 ID 为 `zh`，因此中文资源使用 `locale/zh.json`；`zh-CN.json` 不会被该活动语言命中。
- npm 包名、预设 ID `xiao-he-runtime`、工具名、运行记录格式及安装/更新目标保持不变。

安装后需按宿主方式重新加载（通常为重启 DSH）才会刷新插件列表显示名；发布不自动安装、升级或重启日常 DSH。

## 验证与限制

本说明发布前冻结。宿主 locale 解析路径、locale 文件打包、包白名单、隔离安装及本地回归以本轮 `npm run check`、`npm run verify:package`、`npm run test:install` 的实际输出为准；标签四矩阵 CI、npm 公开字节和 GitHub Release 是否通过以实际流水线和公开制品为准，不预先声称已通过。真实桌面 GUI 刷新效果、真实模型、实际 OS 沙箱和整宿主重启仍未验收。

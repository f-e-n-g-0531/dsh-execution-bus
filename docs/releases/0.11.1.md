# 萧何 / Xiao He 0.11.1

## 修正跨步骤取回说明（pilot 发现）

本版只修正提示与文档，不改变执行机制。

- pilot 发现：同一 PTC 程序内，未完成的 request 会阻塞后发工具调用的结果提交（宿主按提交顺序结算）；在同一程序里“启动后立刻 `status` 轮询”会实际阻塞到执行结束，而不是立即看到 running。
- 模式说明与工具体描述补充正确姿势：启动步骤只发请求并尽早结束程序；下一步再用同一 requestId 的 `status`/`result` 或重发同一 request 附着取回；不要在同一程序里对未完成请求轮询状态。
- `README` 与 `protocol.md` 同步该行为说明；无代码、协议、错误码或 Handler 行为变化。
- 验证：全量 110 项测试通过（提示断言新增该模式的覆盖）。

## 升级说明

需要 DSH 0.2.1-rc.2。只影响模型可见提示与文档，不改变请求结构、状态机或结果语义。不自动安装或重启 DSH。

## 验证与限制

本地全量 110 项测试通过。该行为来自真实 PTC pilot 的组件观察（未做更大规模统计）；真实模型、桌面 UI 与实际沙箱仍未完整验收。

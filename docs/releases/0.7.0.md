# 萧何 / Xiao He 0.7.0

## 宿主工具转发扩展：host.edit 与 host.write

本版在既有 host.read 之外接入两个有副作用的宿主工具，并把幂等声明机制用于真实写操作。

- 新增 host.edit（file_path / old_string / new_string / replace_all?）与 host.write（file_path / content），均经宿主工具管线执行，沿用宿主权限、会话工作目录与沙箱策略。
- 两者显式声明 Handler.idempotent=false：同一 requestId 的终态结果不可复用，重复提交返回 MUTATING_REUSE_DENIED；运行中的重复附着仍只等待同一执行，不会二次执行。
- 抽取出通用 hostToolHandler 工厂与 makeHostInvoke 能力抽象，按 host.<tool> handler 名绑定宿主工具与失败错误码；后续接入只读或写工具无需改动核心代码。
- 新增错误码 HOST_TOOL_FAILED、INVALID_EDIT_INPUT、INVALID_WRITE_INPUT。host.read 行为不变（仍幂等，失败码 HOST_READ_FAILED）。

## 升级说明

需要 DSH 0.2.1-rc.2。本版不强制把原工具改成总线调用，普通任务仍使用原工具；host.edit / host.write 只在你显式提交总线请求时执行。不自动安装、重写日常配置或重启 DSH。历史预设、配置行、工具名、协议字段与既有错误码均不变。

## 验证与限制

本地全量 83 项测试通过（含新增 host.edit / host.write 回归与真实宿主组件测试），包白名单校验通过。真实模型、桌面 UI 与实际沙箱仍未完整验收；状态为进程内存，不支持跨重启恢复。有副作用 Handler 的外部副作用对账仍不在本版范围。

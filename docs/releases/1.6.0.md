# 萧何 / Xiao He v1.6.0

本版新增问题已知悉记录，并改进行动优先展示；不替换 DAG 内核，不引入通知队列或长期自主 Worker。

## 变化

- 新增 `runtime_acknowledge`：原 owner 显式提交当前 attention 的 snapshotHash、事项 key、expectedRevision 和非空理由，记录这一版本的问题已知悉。每个运行最多32条；理由最多2048 UTF-8字节。
- 知悉后事项仍显示，并注明“不等于解决或验收”；普通问题减少重复提醒，未知外部副作用即使知悉仍保留警示和提醒。执行问题版本变化后旧知悉失效，不会压住新问题。
- 首版仅接受已停止调度的 succeeded/failed/cancelled 持久化运行；running/interrupted、活动或清理在途、易失存储失败记录拒绝。成功结果复核仍使用 runtime_review，不提供“已解决”。
- 知悉写入与复核、运行删除共用每run排他锁，在锁内重读并校验 owner、快照和revision；沿用原子保存，不改变执行状态、时间、结果、权限或验收。完整历史由 acknowledge/result 返回，理由不进入状态列表或展示元数据。
- 卡片优先呈现必须处理事项及只读结果入口；成功结果待复核和常规进度留在详情，不触发默认提醒。本页聚合不代表全量待办，不折叠不同运行，不把聚合哈希用于步骤结果分页。
- 未知副作用增加固定核验清单，只读重试退避展示既有策略等待原因；不增加自动重试、恢复、重发或停止 Job。

## 使用与兼容

知悉仅是 owner 会话声明，不证明人工已阅读、问题解决、独立验收或通知投递，也不是回答 Worker、恢复任务或继续执行的授权。状态查询不会自动知悉。

version 1 运行记录新增可选 acknowledgements 字段；旧记录仍可读取，旧版读取器不认识此字段，不应让新旧版本混用记录目录。历史随run既有保留策略清理，不是永久审计库。锁忙拒绝，崩溃遗留锁须在停止所有访问该目录的宿主并备份核验后离线处置，不要在线清锁。

标准 DSH 0.2.2-rc.1 Worker 仍因缺少可信父策略适配器而拒绝；普通工具 DAG、安全门禁、未知副作用不自动重放的规则不变。发布不自动安装、升级或重启日常 DSH。

## 验证与限制

本说明上传前冻结。开发阶段全量构建与回归447项通过，包清单和差异检查通过；发版版本的最终 check、包校验、候选隔离安装及标签四矩阵CI以实际输出为准。npm/GitHub公开产物与候选一致性由发布流程及发布后下载核验确认，不预先声称通过。

真实桌面GUI、真实模型、实际OS沙箱、多进程崩溃注入及整宿主重启尚未验收；静态复核与单元/集成测试不替代这些验收。

# 萧何 / Xiao He v1.7.0

本版改进保留运行的查询、交接与处置，并新增可信宿主扩展和离线业务提示词历史；保留现有 DAG 内核和安全边界。

## 主要变化

- 新增 `runtime_task` 与 `runtime_query`：按任务查看运行，或跨任务筛选待处理事项和待复核结果。仅同 owner 可读；查询不搜索输入及结果正文，候选超限明确拒绝，不静默截取。
- `runtime_status` 列表与任务视图支持成员快照分页：固定成员及顺序，每页仍读取最新状态；缺失成员明确标出，快照过期后需重新获取。
- 新增 `runtime_decision`：记录决策请求已答复、被替代或不再处理，可关联答复引用及已存在的后继运行。处置绑定当前问题版本，不等于用户批准或问题解决，不会回答 Worker 或自动续跑。
- 新增 `runtime_handoff`、计划来源说明与计划差异摘要：显式交接所选结果的版本绑定摘要，区分请求、范围和参考资料；不复用执行成功，不自动获取引用或扩大权限。
- 新增 `runtime_notification` 显式通知回执及宿主发送接口：合并最新内容，拒绝旧回调。发送异常、未知结果或发送后取消不自动重发；投递声明不是已阅读、交付或验收证明。发送器由宿主绑定，不开放给模型。
- 行动摘要优先展示下一步处置；记录目录增加合作式进程独占锁，崩溃遗留锁不自动抢占。存储诊断增加观察时间，不将累计错误当作当前健康状态。
- 整份计划仅含 `read/glob/grep` 时采用完成驱动调度，已完成结果落盘后即可派发依赖已满足的步骤；混合计划保持原有批次隔离，失败、超时、取消或存储故障停止新派发。
- 增加共享容量观察；仅说明观察时准入是否已满，不预留、不排队、不授予重试权限。可信宿主可读取精确聚合，普通 owner 不获得其他会话详情。
- 可信宿主可显式配置上游结果按需分页及模型等待观察；标准插件未启用这些扩展，模型事件缺失不代表健康。
- 包入口提供离线业务提示词预览、比较和最多 32 个修订的历史保存，保留实际观察到的默认正文，旧基线缺失保持 unknown；不应用到 Worker，不允许覆盖安全段。
- 隔离安装检查同步校验本版 13 个注册工具。

## 兼容与升级

目标宿主仍为 DSH 0.2.2-rc.1，技术标识及现有工具保留。标准插件的含 agent 计划仍因缺少可信父策略适配器而拒绝，普通工具 DAG 不受影响。未知副作用和未知 Agent 不自动重放，不保证 exactly-once。

新增可选持久字段不保证旧读取器可识别。升级前备份运行记录；不要让新旧版本或不同宿主进程混用同一记录目录。目录锁只约束遵守协议的 RuntimeService，不是沙箱或分布式锁；离线提示词历史与通知回执也须由可信宿主管理私有目录。

发布不会自动安装、升级或重启日常 DSH。

## 验证与限制

本说明在上传前冻结。最终构建、全量回归、包白名单、候选隔离安装、Windows/Ubuntu × Node 22/24 标签 CI 及公开包一致性，以实际验证输出和 Actions 为准，不预先声称发布成功。

本地验证已完成构建与 643 项回归、144 个打包文件白名单及固定候选的隔离生产安装检查。依赖安装仍报告 36 个受影响包节点（33 high、3 moderate），沿用已披露上游告警，本版未修复；节点数不是独立漏洞数或生产可达性评估。

此前开发全测曾出现一次 native edit 集成失败，后续未复现，根因尚未确定，不标为已修复。真实桌面 GUI、真实模型、实际 OS 沙箱及整宿主重启未验收；组件测试与静态对照不替代这些验收。
